# Chez Maurice

Maurice is a shared AI and memory for families and small groups. A household
runs its own Maurice — on a Mac at home, or hosted in Europe — and each member
has a private space plus the rooms they choose to share.

More at [www.chezmaurice.eu](https://www.chezmaurice.eu).

## What is where

| Repository | What it holds |
|---|---|
| [chez-maurice](https://github.com/chezmaurice/chez-maurice) | Maurice itself: the server, the iOS and macOS apps, the web garden, the browser extension. Start here to self-host. |
| [carnet](https://github.com/chezmaurice/carnet) | Carnet, the iOS companion: capture, reading, the garden in your pocket. It talks to a Maurice server. |
| [maurice-android](https://github.com/chezmaurice/maurice-android) | Maurice and Carnet for Android, Windows and Linux (Kotlin Multiplatform): the `main` branch is the Play Store build, `foss` the Google-free one behind the Obtainium releases. |
| [maurice-android-releases](https://github.com/chezmaurice/maurice-android-releases) | Signed APKs of the Maurice Android app, for Obtainium. |
| [carnet-android-releases](https://github.com/chezmaurice/carnet-android-releases) | Signed APKs of the Carnet Android app, for Obtainium. |
